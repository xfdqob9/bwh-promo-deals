顺带说清两个概念。“循环折扣”的意思是用码买的机器，以后每次续费都按折扣价算，也就是终身折扣；而“优惠码只在下单时生效”，已经付款的订单不能事后补折扣。所以就算以后出了新码，也要在下单那一刻填上，付款后找客服追认是没用的。

在别处看到“搬瓦工最新优惠码”这类标题，可以直接在结账页验证：购物车页有 Promotional Code 输入框，填码后点 Validate Code，显示折扣价就是有效，提示 Invalid 或 expired 就是失效了。整个过程十秒钟，比研究文章快得多。

还有一点容易混淆：部分限量版套餐购买需要“邀请码”，那是另一套机制，和折扣优惠码不是一回事。
